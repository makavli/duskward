## Sound

Every sound is synthesised by `tools/make_sounds.py` from the Python standard library; no recordings are used.

## Art

Everything on screen is drawn by the game's code at run time; there are no image files.

## Engine

[pygame-ce](https://pyga.me) (LGPL 2.1), and [pygbag](https://github.com/pygame-web/pygbag) for the browser build.
